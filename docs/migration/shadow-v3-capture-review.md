# v3 捕获核心：Claude 2026-10-23 审查修改

本 PR 是安装前核心修订，**不是安装包就绪或恢复生产授权**。不执行真实预检，不改生产配置，不启用采集，不重启服务，不发业务请求。真实路径清单/安装交接保留在用户工作区，不提交公开仓库。

## 根目录与媒体

`shallow` 只列根本身和一层子项；`trees` 才允许明确子树递归。证据输出必须落在显式 `exclude` 下，且不能把排除路径再作为文件/树输入。回放将未采子目录标为 `contentsCaptured=false`，枚举这些目录触发缺事实，不能默认为空。新出现日期目录的夹具验证发现元数据并拒绝读取未采内容。

Oracle 的效应盘点只访问已物化输入和被跟踪写入，避免盘点自身为了检查效果而遍历未知占位目录；业务真正遍历时仍由 SandboxIO 拒绝，Oracle退出门禁不变。

媒体摘要为内存增量缓存，身份/大小/mtime/ctime变化就重置；每轮所有媒体累计最多64MiB，超出标hashPending。大文件跨轮计算，完成且身份不变才发布摘要。媒体不复制到证据库。摘要缺失时，依赖摘要的比较继续不可比。

## SQLite

原文件/WAL字节复制改为 `mode=ro`、query_only连接的 SQLite online backup；不执行checkpoint/VACUUM，不拿生产 Store 锁。备份输出、时间范围、页数及耗时进入捕获证明；大小/截止有硬限制，只删除本轮新scratch失败产物。后续物化/行哈希只读取scratch副本。并发WAL夹具验证写入方能提交、成对字段保持一致。

## 先行实测预算（仅隔离夹具）

模拟库139,632,640字节（约133MiB），64KiB块；8次真实在线备份，每次约0.3～0.5秒。测得块+索引增量如下：

| 每次修改记录数 | 每轮新增最大值 | 12小时728次追加快照+基线估算 |
|---|---:|---:|
| 1 | 208,314B | 482,268,842B（约460MiB） |
| 8 | 667,066B | 816,240,298B（约778MiB） |
| 32 | 2,289,082B | 1,997,067,946B，超过1.5GiB |

728次为78个剩余输入×8阶段+32个命令/入箱事件+72次10分钟周期；每轮另加256KiB事实开销是**假设额度**，不是测得的真实目录/状态文件体积。不能拿此表当真实宿主预算通过。

压力场景需降低 DB 频率。新增 DatabaseCadence 候选：变化立即请求快照并必须写变化日志，DB最短120秒合并一次，空闲10分钟一次。12小时最多360次追加快照，按压力场景为1,058,216,778B，再留128MiB变化日志合计1,192,434,506B（约1.11GiB），低于1.5GiB；0.5GiB另留回放/scratch。**120秒合并是对“变化立刻拍DB”的明确预算折衷，须 Claude 核对；不能假称延后时点已有同刻DB快照。**

当前cadence只有票据/状态接口，尚未接入真实变化日志或安装入口；不得启用后无日志地跳过变化。部署前需用 enabled=false 的真实宿主预检重新量测增量和额外事实体积；不达预算就阻止启用，不扩容。

## STOP

宿主新增显式 stop_requested 探针，线程工作前后及空闲每秒检查；发现STOP后在原应用事件循环执行close，恢复GET绑定后退出。原应用不关闭。STOP移除也不能重启已停的对象，必须下次正常启动。夹具验证原GET响应正在读取时仍能完整返回，PID/create_time不变，无重复GET，无自动再启。

## Claude 第二轮审查修订（本次）

- 在线备份改成 `pages=-1`，避免多个复制步骤之间写入导致重新开始。并发 WAL 夹具仍验证写入能继续；新增夹具核对只有一次 backup 调用、最终进度只出现 SQLITE_DONE/remaining=0，写入在备份调用返回前完成。截止检查发生在单个复制步骤返回时，不能宣称可中断这一步。
- 摘要每次读取至多 1 MiB，每轮累计上限不变。媒体读取中增长/变更或暂时不可读只清除该文件摘要、标 hashPending，下轮重算，不否定整轮。窗口末只严格比较目录身份/成员；变动文件保存末次测得元数据并标 writing_or_changed，不能声称其内容稳定。源状态正文、进程、外部响应、明确缺失路径仍严格核对。
- 捕获窗口在事实验证完成时关闭，之后只把冻结输入组装成包；组装时间不冒充采样时间。证明同时保留首末目录清单摘要和摘要待补数量。
- `validate_plan` 直接拒绝 trees 中任何实际盘符根；同时有 shallow/exclude 也不豁免。验证夹具仅做计划验证，不枚举真实盘符。
- STOP 探针异常视为停用：恢复 GET 绑定、停止影子线程、锁定不能重启。启动前探针异常也不绑定。不会结束 Dashboard。
- 只读预检增加三组目录元数据窗口的失败比例、轮数和不可测轮数；有不可测轮数时比例为空，不记作零。任何目录失败标 requires_review。publisher 状态另统计实际尝试轮次、目录失败轮次及比例，限频跳过不进分母。宿主预检 #59 后续需接入这些字段。静态暂停期的低比例不证明活跃批次通过。
- 120 秒合并折衷按 Claude 的有条件同意继续：先接变化日志，延迟时点不可比；启用 observe 前必须完成共享总额度锁。真实宿主禁用多轮量测及恢复首段的真实变化率复核均待完成。
