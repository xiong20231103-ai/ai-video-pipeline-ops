# 真实影子工具：证据审计入口（第一阶段）

本PR不是完整实时采集器，也不是R1～R5真实验收通过记录。不会修改、替换或重启生产；不会打开迁移指针或开关。依赖PR49的固定历史源码文本，PR48旁听格式作为只读输入。

## 已实现

- tools/shadow_audit.py显式指定证据目录、批次、带时区的时间窗口、生产源码和新输出路径。
- 逐个核对内容寻址对象的大小和SHA256，拒绝越界引用、符号链接、变化中的文件、重复对象归属和含私密字段的数据；报表仅保留白名单任务身份/计数/状态，不复刻正文或错误消息。
- 按精确batchId归属，不按日期、文件名或上次活跃项目猜测。观察到的状态不当作独立验证的生产完成事实。
- 总对象读取2GiB、对象64MiB、清单8MiB、每样本1万引用、3000样本、默认30秒审计上限（最大120秒）。缓存只保留摘要，不保留整批正文。超时、配额、截断和缺失均列为阻塞，不能记通过。
- 核对生产源码与候选固定基线哈希，不把PR49后生产源码伪装为f78db5a。
- comparable、realShadowPassed、switchAccepted固定false；即使输入声称通过也不采用。未来真实对比工具必须从可信捕获与实际回放结果计算结论，不能手工把这些值改true。

## 用法

在独立worktree离线运行：

```powershell
python -B tools/shadow_audit.py --evidence E:\Backup\ops-shadow-data-v2 --batch-id formal-batch-1792032628470-924e109b0a --since 2026-10-20T23:57:00+08:00 --until 2026-10-21T15:06:40+08:00 --source <只读生产app.py路径> --out <新的worktree报告路径>
```

不会改证据文件，输出不得位于证据目录中；已存在输出拒绝覆盖。此命令不是生产服务安装入口。
