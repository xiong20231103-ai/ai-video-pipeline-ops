# 真实批次旁听记录器：仅证据，不授予切换资格

`tools/passive_shadow.py` 独立运行。复用已审备份白名单的非私密 JSON；排除配置、密钥、CSV、原始日志、媒体和代理执行库。正文经秘密字段/文本检查才保存。SQLite 主库/WAL先稳定复制到独立scratch，再只在副本查询；从不对生产SQLite建立连接，避免只读连接仍写共享内存。

每600秒记录一次，20秒正文采集预算，文件大小/mtime未变时复用已检查正文的内容哈希。超过预算记budgetHit，未访问对象不伪称本轮已观测。内容寻址去重，2GiB上限后停止增加正文、不自动删除历史。变化窗口、不完整/秘密数据明确计数；输出路径不得与来源相交，符号链接拒绝。只创建独立输出下的状态、证据和进程锁。无HTTP、POST、子进程、生产app导入、迁移设置和开关操作。

events/task_history/heartbeats首次只记录最大rowid游标，不在家里回填数月旧历史；之后记录新增行。tasks/source_health保存当前投影。此记录器只能支持安装之后的批次取证，历史全量回放需单独对已审快照进行，不能从本工具的基线游标声称历史覆盖完成。

**重要边界：这是取证，不是完整影子比较器。** 不具备冻结且对齐的文件系统/进程/外部响应事实；`comparable=false`、`realShadowPassed=false`。周三周四数据只能作为真实批次证据的一部分，不能据此宣布R1～R5零差异或周五切换。完整离线重放须补齐审查过的recipe及各模块真实触发覆盖；缺失一项就延后相应切换。

安装到独立目录，使用现有pythonw隐藏启动；用户Startup仅新增一个本项目VBS，无任务/看门狗变更。安装前备份独立目录及既有同名入口；回滚写独立STOP、等锁释放并还原入口，不停止家里程序、不删除生产数据。用户要求的批次期间冻结仍适用。
